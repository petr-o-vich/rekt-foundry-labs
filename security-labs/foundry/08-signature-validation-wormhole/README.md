# Wormhole (signature validation class) — lab

Кейс: Wormhole — https://rekt.news/wormhole-rekt/

## Эксплойт (3–4 шага)
1. Мост принимает сообщение, если собрано `threshold` валидных подписей guardians.
2. В vulnerable-логике подписи считаются «по количеству совпадений», без проверки уникальности signer index.
3. Атакер повторно подает одну и ту же валидную подпись и тот же guardian index несколько раз.
4. Порог формально выполняется, сообщение считается подтвержденным.

## Баг (1 строка)
Подсчет кворума по валидным подписям без проверки уникальности подписантов.

## Фикс (1 строка)
Считать только уникальные guardian index (bitmap/seen-check) и отклонять дубли.

## Идея теста в Foundry
`testReplaySingleGuardianSignatureCountsAsQuorum` показывает bypass на vulnerable; `testDuplicateGuardianIndexReverts` подтверждает, что fixed блокирует дубли.

## Чеклист (макс 3)
- Проверять уникальность signer index при верификации мультисиг-сообщений.
- Сравнивать кворум с количеством **уникальных** валидных подписантов.
- Добавить негативный тест на повтор одного и того же `index+signature`.
